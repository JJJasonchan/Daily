# 壁纸取色玻璃侧栏与今日完成进度设计

## 目标

为 Daily 的主窗口加入与当前系统桌面壁纸协调的轻量背景色，同时提升侧栏的玻璃层次，并在今日页直观展示当天完成量。

## 范围

- 读取主屏当前桌面壁纸，提取适合界面使用的低饱和主色。
- 用该颜色生成侧栏背景的轻微渐变；不在应用中直接绘制或保存壁纸图像。
- 调整侧栏导航选中态和今日进度卡片的半透明材质、模糊和描边。
- 将今日页右上角进度改为全圆环，展示完成百分比与完成数量。
- 保持现有今日任务数据、持久化模型和任务完成逻辑不变。

## 壁纸取色与刷新

新增一个仅负责界面颜色的提供者：

- 从当前主屏的 `desktopImageURL` 加载壁纸缩略图并计算平均颜色。
- 将取样颜色限制为中低饱和度、中等亮度，避免过亮、过暗或高饱和壁纸降低可读性。
- 基于该颜色生成两个透明色阶，形成由左上至右下的细微渐变。
- 监听 macOS 壁纸变更通知；通知到达后重新取色并使用短暂淡入过渡更新侧栏。
- 无法读取壁纸或取色失败时，使用当前系统窗口材质和中性色回退，应用继续正常工作。

## 侧栏视觉

- 侧栏底色为壁纸取色渐变叠加系统材料，以保留桌面环境的综合色感。
- 导航项保留紧凑布局；悬停使用低强度白色或主色叠层，选中项使用更明显的半透明填充。
- 今日进度卡片使用约 76% 等效不透明度的玻璃表面、背景模糊、轻描边和克制阴影。
- 进度卡片继续显示任务完成数量，并使用小型圆环表示比例。
- 当“减少透明度”开启时，渐变和模糊退化为不透明系统窗口背景与高对比描边。

## 今日完成圆环

- 今日页标题区右侧使用完整圆环，而非半圆仪表盘。
- 圆环中心显示 `今日完成`、百分比和已完成数量；下方显示 `已完成 / 总任务 tasks`。
- 分子来自 `completedCount`，分母来自 `todayTasks.count`，比例来自 `completionFraction`。
- 空任务时显示 0%、0 / 0，并保留弱化的底环，避免除零或空白布局。
- 任务完成、撤销完成或添加、删除任务时，圆环弧线和数字使用既有动态策略同步过渡；“减少动态效果”开启时仅即时更新。

## 结构与测试

- 壁纸颜色逻辑与 SwiftUI 视图分离，使其可单独提供回退值和测试取色结果。
- 侧栏只消费颜色状态，不读取桌面壁纸。
- `ProgressRing` 扩展为可选的圆环样式，避免影响侧栏的小型进度样式。
- 补充或调整测试，覆盖空任务、部分完成、全部完成的环形进度文本与比例；运行完整 Swift 测试和应用构建验证。
